# ShopHub — E-Commerce Website

A responsive e-commerce website built with HTML, CSS, and JavaScript.

## Features
- Product listing with dynamic rendering
- Real-time search and category filter
- Sort by price (low to high / high to low)
- Add to cart with localStorage persistence
- Quantity update and item removal
- Toast notifications
- Responsive mobile design

## Pages
- `index.html` — Home page with featured products
- `products.html` — Full product listing with filters
- `cart.html` — Shopping cart with order summary

## Tech Stack
HTML · CSS · Vanilla JavaScript
